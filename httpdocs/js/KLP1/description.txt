KLP: консервативные летающие клетки
===================================

Этот файл описывает актуальную реализацию KLP.


1. Состояние
------------

В клетке хранится

    state = (R,G,B,A) = (rho, px, py, U),

где rho — масса, (px,py) — импульс, U — некинетическая энергия. Скорость и
полная энергия клетки вычисляются:

    velocity = (px,py)/rho.
    E = U + (px^2+py^2)/(2 rho).

Отдельных координат и идентификаторов частиц нет.

Три слоя трёхмерной текстуры содержат независимые виды материи: cyan, purple
и yellow. У каждого вида своя стандартная масса частицы и своя сила
отталкивания. В дальнейшем можно добавить четвёртый слой.


2. Перенос площади
------------------

За один физический шаг квадрат смещается на

    move = clamp(dt * velocity, -maxMove, maxMove).

Площадь его пересечения с каждой из четырёх целевых клеток задаёт вес:

    weight(d) =
        max(0, 1-|d.x-move.x|)
      * max(0, 1-|d.y-move.y|),

где d — целочисленное смещение центра целевой клетки. Четыре ненулевых веса
неотрицательны и в сумме равны единице.


3. Компенсация дискретизации
----------------------------

Попавшая в целевую клетку доля считается оказавшейся в её центре. Ошибка
такого округления:

    error = d - move.

Ей назначается скорректированная скорость:

    correction = min(focus * max(abs(move.x),abs(move.y)), 1),
    streamVelocity = velocity - correction * error / dt.

Ошибка исправляется не за один такт, а примерно за время пересечения одной
клетки. Поэтому корректирующая скорость остаётся порядка исходной скорости.
Рано попавший в будущую клетку фрагмент почти ждёт там, пока основная масса
его догонит. Фрагменты остаются компактной группой около средней траектории,
не накапливая диффузионное размытие.

Ключевое свойство: средняя ошибка с весами площадей равна нулю:

    sum weight(d) * (d-move) = 0.

Следовательно, корректирующие импульсы взаимно компенсируются.


4. Попарное отталкивание
------------------------

Соседние клетки одного вида сталкиваются, если их суммарная масса превышает
стандартную массу частицы и они движутся навстречу друг другу. Им назначаются
равные противоположные импульсы вдоль линии центров. Величина импульса зависит
от встречной относительной скорости, приведённой массы и избытка массы.

При максимальном отклике нормальная составляющая относительной скорости
отражается упруго. Более слабый отклик гасит часть относительного движения,
переводя его кинетическую энергию в U. Неподвижные клетки не могут
самопроизвольно разогнаться.

5. Межслойное связывание
------------------------

Связывание разных видов начинается только после их попадания в одну клетку.
Их скорости выравниваются равными противоположными импульсами, а потерянная
относительная кинетическая энергия переходит в U. Совпавшие по положению и
скорости частицы продолжают лететь вместе как устойчивый комплекс. Сила
связывания зависит от обоих видов материи.


6. Энергия
----------

Коррекция создаёт разброс скоростей, то есть переводит часть внутренней
энергии в кинетическую. Для каждого источника заранее вычисляется средняя
кинетическая энергия четырёх потоков:

    fraction = fract(abs(move)),
    variance =
        fraction.x(1-fraction.x)
      + fraction.y(1-fraction.y),

    meanKinetic =
        (|velocity|^2 + correction^2 * variance / dt^2) / 2.

Некинетическая энергия потока на единицу массы равна

    streamU = U/rho + |velocity|^2/2 - meanKinetic

и может быть отрицательной. Фрагменты в этом смысле виртуальны: отрицательные
и положительные вклады компенсируются при сложении. При слиянии потоков потеря
кинетической энергии относительного движения добавляется в U. Поэтому сумма
полной энергии потоков точно равна энергии источника.


7. Законы сохранения
--------------------

Для каждого источника веса дают единицу, средняя коррекция импульса равна
нулю, энергетическая поправка построена с нулевой суммой, а все попарные
импульсы взаимодействий антисимметричны. Любое изменение кинетической энергии
при взаимодействии компенсируется противоположным изменением U. На торе в
точной арифметике:

    sum rho = const,
    sum px  = const,
    sum py  = const,
    sum (U + (px^2+py^2)/(2 rho)) = const.

На GPU остаётся только обычная погрешность float32 при сложении. Отдельной
конденсации или неконсервативной нормализации нет.


8. Начальное состояние
----------------------

В каждом слое каждая клетка пространства независимо заполняется с небольшой
вероятностью, задающей ожидаемое число частиц данного вида. Направление и
величина начальной скорости выбираются случайно. Начальная некинетическая
энергия равна нулю.


9. Ожидаемая динамика
---------------------

* Изолированная клетка летит по прямой, занимая не более четырёх клеток.
* Дробный перенос не накапливает размытие.
* В целочисленных точках траектории масса снова собирается в одной клетке.
* Встречные частицы одного вида сталкиваются, не получая энергии из ничего.
* Частицы разных видов могут слипнуться при контакте и лететь как молекула.
