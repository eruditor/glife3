KLP: консервативные летающие клетки
===================================

Этот файл описывает актуальную реализацию KLP.


1. Состояние
------------

В клетке хранится

    U = (R,G,B,A) = (rho, px, py, E),

где rho — масса, (px,py) — импульс, E — полная энергия. Скорость вычисляется:

    velocity = (px,py)/rho.

Отдельных координат и идентификаторов частиц нет.


2. Перенос площади
------------------

За один физический шаг квадрат смещается на

    move = clamp(dt * velocity, -maxMove, maxMove).

Площадь его пересечения с каждой из четырёх целевых клеток задаёт вес:

    weight(d) =
        max(0, 1-|d.x-move.x|)
      * max(0, 1-|d.y-move.y|),

где d — целочисленное смещение центра целевой клетки. Четыре ненулевых веса
неотрицательны и в сумме равны единице.


3. Компенсация дискретизации
----------------------------

Попавшая в целевую клетку доля считается оказавшейся в её центре. Ошибка
такого округления:

    error = d - move.

Ей назначается скорректированная скорость:

    streamVelocity = velocity - focus * error / dt.

При focus=1 на следующем такте все четыре фрагмента исходной клетки летят к
одной и той же непрерывной точке. После смешивания они снова занимают не более
четырёх клеток вокруг точной траектории. Поэтому ширина пятна не растёт со
временем. Когда точная траектория проходит через центр клетки, вся масса
собирается в этой одной клетке.

Ключевое свойство: средняя ошибка с весами площадей равна нулю:

    sum weight(d) * (d-move) = 0.

Следовательно, корректирующие импульсы взаимно компенсируются.


4. Попарное отталкивание
------------------------

Перед переносом каждая пара соседних непустых клеток получает противоположные
импульсы, если

    mass1 + mass2 > repulsionThreshold.

Модуль импульса пропорционален превышению порога и приведённой массе пары:

    impulse = dt * repulsion
        * mass1*mass2/(mass1+mass2)
        * (mass1+mass2-repulsionThreshold).

Диагональные соседи действуют слабее пропорционально обратному расстоянию.
Обе стороны независимо вычисляют равные противоположные импульсы, поэтому
суммарный импульс не меняется. У нормальной частицы полной массы 1 сумма любых
двух её фрагментов не больше 1, поэтому собственные фрагменты не отталкиваются.

5. Энергия
----------

Коррекция создаёт разброс скоростей, то есть переводит часть внутренней
энергии в кинетическую. Для каждого источника заранее вычисляется средняя
кинетическая энергия четырёх потоков:

    fraction = fract(abs(move)),
    variance =
        fraction.x(1-fraction.x)
      + fraction.y(1-fraction.y),

    meanKinetic =
        (|velocity|^2 + focus^2 * variance / dt^2) / 2.

Остаток E/rho - meanKinetic считается удельной внутренней энергией. Энергия
каждого потока равна его массе, умноженной на сумму этой внутренней энергии и
его собственной кинетической энергии. Поэтому сумма энергий потоков точно
равна энергии источника.

Начальная localizationEnergy = focus^2/(4 dt^2) — запас на максимальный
двумерный разброс скоростей. thermalEnergy добавляет свободный запас.


6. Законы сохранения
--------------------

Для каждого источника веса дают единицу, средняя коррекция импульса равна
нулю, энергетическая поправка построена с нулевой суммой, а попарные импульсы
отталкивания антисимметричны. Энергия клетки при отталкивании не меняется:
кинетическая энергия берётся из её внутренней энергии. На торе в точной
арифметике:

    sum rho = const,
    sum px  = const,
    sum py  = const,
    sum E   = const.

На GPU остаётся только обычная погрешность float32 при сложении. Отдельной
конденсации или неконсервативной нормализации нет.


7. Начальное состояние
----------------------

Каждая клетка пространства независимо заполняется с небольшой вероятностью,
задающей ожидаемое число частиц. Направление и величина начальной скорости
выбираются случайно. Начальная энергия включает кинетическую,
локализационную и тепловую части.


8. Ожидаемая динамика
---------------------

* Изолированная клетка летит по прямой, занимая не более четырёх клеток.
* Дробный перенос не накапливает размытие.
* В целочисленных точках траектории масса снова собирается в одной клетке.
* Перекрывающиеся частицы создают локальный избыток массы и отталкиваются.
