KLP: перенос вещества по квадратной решётке
============================================

Состояние клетки состоит из двух RGBA-плоскостей:

    layer 0 = (M, E, 0, 0),
    layer 1 = (cx, cy, vx, vy),

где E — внутренняя (избыточная) энергия. При M=0 вторая плоскость считается
нулевой. Во время расчёта потоки суммируются как первые моменты M*c и импульсы
M*v, после чего результат нормируется обратно в c и v.

За такт приёмник читает источники из окрестности 3x3. Для источника с M>0
центр массы и скорость читаются из второй плоскости. По каждой оси
восстанавливается интервал:

    [0, 2c],       если c <= 0.5;
    [2c - 1, 1],   если c > 0.5.

Плотность прямоугольника равна M, делённой на его площадь. Прямоугольник
сдвигается на v*dt; dt при необходимости уменьшается так, чтобы ни одна
компонента сдвига не превышала одну клетку. Каждое пересечение с приёмником
добавляет:

    (m, m*xc, m*yc, m*vx, m*vy),

где (xc,yc) — центр пересечения в локальных координатах приёмника.

Если в одну клетку приходят несколько потоков, они неупруго объединяются.
Их скорость становится равной суммарному импульсу, делённому на массу.
Потеря кинетической энергии добавляется в E, поэтому сохраняются масса,
импульс и полная энергия E + M*|v|^2/2.

Начальное состояние содержит N частиц массы 1 в разных случайных клетках
(параметр n, по умолчанию 128). Каждая начинается в центре своей клетки и
получает случайное направление и случайную скорость меньше 0.1. Верхняя
граница скорости задаётся параметром speed и принудительно ограничена 0.1.
